2,299 convergence warnings, 305 `fit_failed` records and 8,194 features with
insufficient nonzero support. Its 5,158 BH-significant features are historical.

Full baseline feature TSVs are compressed. The LMM table was normalized from
the legacy unquoted multiline diagnostic format with
`benchmarks/read_legacy_lmm_tsv.R`; diagnostic newlines become literal `\n`.

checksums and session information are retained. Do not combine baseline fit
counts or q-values with the current robust results.

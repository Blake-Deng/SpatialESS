# SpatialESS

[![R-CMD-check](https://github.com/Blake-Deng/SpatialESS/actions/workflows/R-CMD-check.yml/badge.svg)](https://github.com/Blake-Deng/SpatialESS/actions/workflows/R-CMD-check.yml)
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23641420.svg)](https://doi.org/10.5281/zenodo.23641420)

SpatialESS is an R package for spatial cell–cell communication inference. It
uses sparse radius graphs and streamed ligand–receptor scoring and permutation
tests, with numerical validation against the tested SpatialCellChat V3 workflow.
For cohorts with repeated tissue sections, it also provides patient-aware
mixed-effects analysis.

## Get started

Requires **R ≥ 4.1** and a **C++17 compiler**.

```sh
git clone https://github.com/Blake-Deng/SpatialESS.git
cd SpatialESS
Rscript -e 'install.packages(c("Rcpp", "Matrix", "future.apply"))'
R CMD INSTALL .
Rscript examples/lr_panel_example.R
```

The example uses synthetic data and needs no external dataset or CellChat
installation. For cohort modelling, also install `lme4`.

To analyze your own data, follow the [analysis guide](docs/QUICKSTART.md) and
[input requirements](docs/INPUTS.md). Expression matrices are gene-by-cell;
coordinates and cell-type labels must follow the same cell order. Required
ligand and receptor subunits must be measured; excluded interactions are
reported in an explicit coverage audit.

## Official-reference p-value alignment

The development version uses `aggregation = "reference"` by default: each LR
is still processed sparsely, but group aggregation follows the same complete
Matrix/BLAS operations as the tested SpatialCellChat V3 reference. This mode
needs dense cell-by-group workspaces and enforces `max_reference_entries` before
allocating them. It never silently falls back to a different reduction order.
The explicit `aggregation = "stream"` option retains the previous low-memory
reduction for engineering workloads; last-bit ties can produce different p-values.
The statistical rule remains strict `Pboot > Pobs`, with `count / nboot`.

`future.apply` is now a runtime dependency so the reference's RNG advance is
not conditional on optional-package availability. Exact comparison still requires
matched input order, reference version, R/RNG settings and numerical libraries.
See [the alignment change notes](docs/PVALUE_REFERENCE_ALIGNMENT.md) and
[matched-environment validation](docs/validation/pvalue_reference_20261113/README.md).

## Visium HD: bin8, bin16 and bin32 (development)

This development version reads sparse Space Ranger binned counts and runs
RCTD independently at each requested resolution. Missing coarser resolutions,
including bin32, can be generated by summing finer raw-count bins on the
capture grid. RNA/UMI contribution proportions, quality exclusions and dominant-type
bin labels are retained. Optional downstream SpatialESS analysis uses the
observed bin expression and dominant type; it does not reconstruct single cells.

See the [Visium HD server guide](docs/VISIUM_HD_RCTD.md) and
[configuration example](examples/visium_hd_rctd_config.R). RCTD requires the
original `dmcable/spacexr` API. MEX + CSV inputs need no HDF5/Parquet reader;
native H5 and Parquet inputs additionally use `hdf5r` and `arrow`. Coarsening
requires raw counts and a consistent feature-ID policy by default. See the
[method evidence and publication limits](docs/VISIUM_HD_METHODS_EVIDENCE_20261110.md).

Real-data engineering checks and their limits are recorded in the [server validation summary](docs/visium_hd_validation/20261110/README.md).

## Patient-aware analysis

SpatialESS retains individual sections and accounts for repeated sampling:

```text
log1p(score) ~ condition + (1 | patient)
```

Estimates are reported on the log1p-score scale. BH correction includes fits
with `status == "ok"`, including valid singular fits. See the
[model definitions and diagnostics](docs/MULTISAMPLE_LMM.md).

The repository contains software, analysis scripts, documentation and the
self-contained condition-support tables. Manuscript figures and larger saved
results are supplied through the companion data package described in the
reproduction guide. Raw expression matrices and manuscript Word drafts are
not included.

Observed support and condition association answer different questions. A
feature shared across conditions can still have a significant condition
association; a zero score does not establish biological absence. Numerical
agreement with a reference workflow does not establish biological validity.

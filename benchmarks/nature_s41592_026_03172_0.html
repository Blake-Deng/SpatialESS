Inference of secreted protein signaling activities in intercellular communication

Abstract

The human genome encodes ~1,900 secreted proteins, many of which mediate intercellular communication. Secreted proteins do not act cell-autonomously, limiting systematic approaches to characterize their functions. Here we introduce SecAct (Secreted Activity, https://secact.ccr.cancer.gov), a computational framework that infers the signaling activities of 1,170 human secreted proteins from spatial, single-cell and bulk transcriptomic data. The inference model harnesses precomputed intercellular signaling signatures trained on 1,258 spatial transcriptomics samples spanning 37 cancer types. Transcriptomics data from antisecreted protein therapies validate SecAct’s accuracy in predicting the repression of secreted protein activity following treatment. For spatial and single-cell transcriptomics data, SecAct provides interactive modules for analyzing secreted protein-mediated cell–cell communication. Applying SecAct to 54 cancer immunotherapy cohorts comprising 5,174 patients, we identified secreted proteins associated with tumor immunity. In vivo experiments validated lymphocyte antigen 86 (LY86), whose function in cancer was previously unknown, as an antitumor regulator.

Data availability

The tumor ST data used for training secreted protein signatures described in Supplementary Table 1 are available via Zenodo at https://doi.org/10.5281/zenodo.17664022 (ref. 74) and the SecAct webportal for interactive exploration (https://secact.ccr.cancer.gov → ST Atlas). The signaling risk scores computed using the CIDE cancer immunotherapy datasets for secreted proteins are available for interactive exploration on the CIDE web portal (https://cide.ccr.cancer.gov, Gene Search → SecAct data type). The RNA-seq data of Ly86 OE are available via NCBI GEO under accession GSE291028. The list of 1,903 genes coding secreted proteins was collected from the Human Protein Atlas (HPA; https://www.proteinatlas.org/humanproteome/tissue/secretome) on 10 August 2022. The Cancer Genome Atlas (TCGA) data are available at https://gdc.cancer.gov. The International Cancer Genome Consortium (ICGC) data are available at https://platform.icgc-argo.org (previously hosted at https://dcc.icgc.org). The Clinical Proteomic Tumor Analysis Consortium (CPTAC) data are available at https://pdc.cancer.gov. Pan-cancer proteomic data of human cell lines (ProCan-DepMapSanger) are available at https://cellmodelpassports.sanger.ac.uk. For the validation section, the data source of 18 antisecreted protein-treated clinical datasets is listed in Supplementary Table 3; the data source of 27 cancer scRNA-Seq datasets is listed in Supplementary Table 6. For downstream application 1, the liver cancer Visium data are from this study31; the liver cancer CosMx data are available at https://nanostring.com/products/cosmx-spatial-molecular-imager/ffpe-dataset/human-liver-rna-ffpe-dataset/. For downstream application 2, the ovarian cancer scRNA-Seq data are available at https://doi.org/10.17632/rc47y6m9mp.2; the pan-cancer scRNA-seq atlas is available via Zenodo at https://doi.org/10.5281/zenodo.15554080 (ref. 75). For downstream application 3, the immunotherapy cohorts listed in Supplementary Table 10 are available at https://cide.ccr.cancer.gov. Source data are provided with this paper.

Code availability

The source code of the SecAct R package is available via GitHub at https://github.com/data2intelligence/SecAct and via Zenodo at https://doi.org/10.5281/zenodo.15006880 (ref. 76). A Python implementation covering the core functionality of SecAct is available via GitHub at https://github.com/data2intelligence/SecActpy to support users who work only in Python environments. The SecAct Shiny server for querying the spatial relationship between secreted proteins and targets is publicly available at https://secact.ccr.cancer.gov or https://appshare.cancer.gov/SecAct. The scripts to reproduce the main results are available via GitHub at https://github.com/data2intelligence/SecAct_main. The tutorial and R code for Moran’s I calculation is available at https://data2intelligence.github.io/SpaCET/articles/SpatialCorrelation.html. The C-implementation code for fast Moran’s I calculation is available via GitHub at https://github.com/data2intelligence/SigDiscov.

Extended Data Fig. 2 Evaluation of secreted protein signatures.

a, Pearson correlations of secreted protein coding-gene expression and their signature scores in the TCGA (n = 32) and ICGC (n = 12) cohorts. Each dot represents a secreted protein signature (n = 929) derived from the melanoma ST sample in Fig. 1b. We shuffled the gene identities of each secreted protein signature ten times and computed the average r values as random controls. For the boxplot, the thick line represents the median value; the bottom and top of the boxes are the 25th and 75th percentiles (interquartile range); the whiskers encompass 1.5 times the interquartile range. P-values were computed by the two-sided Wilcoxon signed-rank test, comparing paired values between real and random correlations. ‘p < 2.2e-16’ computed from R language reflects the lower limit of numerical precision in double-precision floating point. The exact p-values are smaller than this bound and therefore cannot be represented more precisely. b, Pearson correlations between the expression of secreted protein-coding genes (n = 1792) or intracellular protein-coding genes (n = 11,963) and their signature scores across tumors in the TCGA and ICGC cohorts. The y-axis presents the average r value across 1,258 tumor ST samples. The values are shown using violin plots, smoothed by a kernel density estimator. The boxplots are shown as in panel a. P-values were computed by the two-sided Wilcoxon rank-sum test and shown as in panel a. c, Lambda value optimization of ridge regression. Each dot represents a TCGA (n = 32) or ICGC (n = 12) cohort. The y-axis presents the median Pearson correlations across 1,170 secreted proteins. For each secreted protein, the Pearson correlation was computed between the coding-gene expression and inferred activity across tumors. The lambda value in red color achieves the optimal value. The boxplots are shown as in panel a.

# SpatialESS development report — 2026-07-30

## Scope completed

A new package prototype was created independently of the frozen CellChatESS
v0.2.1 source. The current implementation contains:

- deterministic C++ uniform-spatial-hash radius graphs;
- sample isolation and optional compartment barriers;
- directed k-nearest-neighbor graphs with a maximum-radius guard;
- a brute-force radius oracle for exact small-data validation;
- simple single-gene expression-supported LR edge scoring;
- CellChat-form Hill activation on the edge-local molecular product;
- a matrix-free graph reaction-diffusion steady-state solver using
  Jacobi-preconditioned conjugate gradient;
- runtime, structural and mass-balance diagnostics.

## Automated validation

All 36 assertions pass.

Graph checks include exact edge, distance and weight agreement with the
brute-force oracle; absence of duplicate, cross-sample and disallowed
cross-compartment edges; deterministic results after cell reordering; and kNN
structural validity.

LR checks include the declared molecular product and Hill formula, expression
support filtering, zero-support output and expression/graph cell alignment.

Field checks include a two-node analytic solution, the zero-diffusion limit,
compartment blocking, named-vector alignment, zero-source behavior,
non-negative concentration, solver residual and mass balance.

## Current boundaries

- The G1 scorer currently supports simple single-gene LR pairs only.
- The edge-local score is a new spatial primitive; it is not yet the
  CellChat-compatible group triMean path.
- Complexes, agonists, antagonists and coreceptors remain to be implemented.
- Exact segmentation-contact adjacency is not possible with the currently
  downloaded centroid-only Xenium files.
- The sampled 4,995-cell graph is a correctness smoke test, not a scaling
  benchmark.
- The current R data-frame edge representation should not be used for the full
  1.156-million-cell graph because materializing tens of millions of rows could
  dominate memory.

## Full prepared-Xenium CSR milestone

The exact manuscript-scale prepared object was matched to coordinates and
processed with 1,156,091 cells, 648 signaling genes, 627 LR records and 2,357
grid groups.

The 30-um Gaussian CSR graph contains 24,417,532 directed edges, has mean
degree 21.1208, median degree 22, maximum degree 59 and 355 isolated cells. The
compact graph object is 389.88 MiB. Core graph construction took 2.897 s and
full edge validation took 0.137 s. All invariants passed. The independent
process, including loading the full prepared CellChat object and coordinates,
used 2,926,720 kB maximum RSS.

The raw Xenium cells table contains 1,157,659 segmented cells. Its independently
constructed graph contains 24,447,454 edges and used only 644,540 kB peak RSS
when the prepared CellChat object was not loaded. The 1,156,091-cell graph is
the canonical benchmark because it exactly matches the prior manuscript
configuration.

## Full five-LR streamed milestone

The five highest expression-support simple LR pairs were streamed over the
complete graph. Core scoring took 5.955 s. The method visited 65,122,278
LR-specific outgoing edges, retained 48,837,340 expression-supported LR edges
and emitted 78,647 sparse LR-group-pair records. The in-memory aggregate result
was 6.65 MiB. The independent process used 3,831,932 kB maximum RSS.

An initial LR-priority calculation used integer multiplication and overflowed.
That selection-only issue was corrected by casting support counts to double,
and the reported run was repeated from the beginning. No score kernel was
affected.

## Full graph-field milestone

The SEMA4C-PLXNB2 steady-state field was solved on all 1,156,091 cells and
24,417,532 edges. The CSR PCG solver converged in 43 iterations and 5.127 s
core time at tolerance 1e-8. Relative residual was 9.827e-9 and relative
mass-balance error was 2.040e-11. The minimum concentration was -1.349e-12,
which is numerical tolerance noise, and the maximum was 0.849519. The
independent process used 3,164,764 kB maximum RSS.

A weighted-degree defect was found by the Gaussian CSR-versus-expanded solver
test before the full run. The CSR operator had initially used neighbor count
instead of the required sum of edge weights. The implementation now stores or
reconstructs weighted degree; all 63 current assertions pass, including
Gaussian solver equivalence and mass balance.

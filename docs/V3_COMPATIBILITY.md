# SpatialCellChat V3 Compatibility Contract

The reference is SpatialCellChat commit
`be88f300464cf970b36a6165ea7d2e41a47a7511` (package version 0.1.0).
The workflow generation V3 is not the same as the CellChat 2.x package version.
Database contents, not merely a database variable name, must be frozen.

The acceptance target is cell scoring with `distance.use=TRUE` and group
aggregation with `avg.type="avg"`, `colocalization.use=FALSE`, and global
label permutations. It does not certify every optional V3 mode, group-sum
aggregation, or a different upstream preprocessing choice. `min.cells.sr`
follows the pinned implementation's sum of nonzero sender/receiver links;
do not substitute a distinct-cell count based only on the parameter name.

## Percentage filter fixed in 0.1.3

Official `computeAvgCommunProb_LR_Avg()` formats each aggregated positive-cell
fraction column with `format(dataLR_temp[, -1], digits=1)` before comparing
with `min.percent`. Version 0.1.2 compared the original numeric fractions.
For example, 8/82 can format as `"0.10"` in its column and pass an official
0.1 cutoff while failing the old ESS comparison. This affects both observed
support and permutation p-values. It is not just display formatting.

Version 0.1.3 calls the same base-R data.frame formatting and comparison for
the small group-level table inside its streamed calculation. No dense
cell-by-cell expression or probability array is introduced. R's formatting
options and locale should therefore also be recorded and kept equal between
engines. Do not approximate this rule with `round(x, 1)` or `signif(x, 1)`.
CSR geometry, Hill scoring, and the global label-permutation definition are
unchanged. The zero-threshold path retains its all-pass fraction mask.

The real-data regression fixture contains official V3 outputs, not outputs
generated by the repaired ESS. Unit tests compare active records, maximum
probability difference, exact p-values and significance, including permutations.

## Same inputs means the same prepared inputs

Freeze expression values and gene rows, cell order, coordinates and units,
group labels and levels, database/complex/cofactor tables, selected LR, all
parameters, and seed/RNG settings. The global expression maximum is computed
over the supplied matrix, so differing gene subsets can change probabilities.

Coverage filtering asks whether mandatory genes/subunits are present. MERINGUE
asks a different question about spatial variability. A database of 1076
covered LR does not mean that all 1076 reach official inference after MERINGUE.
The actual default official LR input is `chat@LR$LRsig`. For a fixed-candidate
benchmark, explicitly pass the shared table as official `LR.use` and ESS `lr`.
Preserve database row names. Explicit `LR.use` also invokes official category
ordering before contact/diffusion dispatch.

ALRA and MERINGUE are external upstream steps, not built into `spatialess()`.
Use both on a shared prepared object or use neither for a candidate-LR test.
SPARKLE similarly changes the upstream expression input; its corrected matrix
must be shared between the two engines in a corrected-input comparison.

## Geometry and zero results

The original distance constructor can infer a matrix smaller than NC when
trailing cells have no other sampled neighbors. Preserve original failure
logs. A separately identified official copy may add only `dims=c(NC,NC)` to
the distance sparseMatrix call. Do not silently edit the installed reference.
Subsequent official self-contact/self-weight handling is retained, not removed.

Center/ROI sampling and global proportional sampling both belong in validation.
Global proportional sampling preserves type composition, not local spatial
neighborhoods. Disconnected or sparse samples should not be interpreted as a
full-tissue biological communication experiment.

The official distance guard requires a minimum scaled distance of at least 1.
Choose a documented shared `scale.distance` that passes this guard; ESS allowing
a smaller positive scale is not evidence that official inference completed.

`computeCommunProb()` returns `net$prob.cell`, not group-level p-values.
`computeAvgCommunProb()` performs group averaging and permutation. Verify:

```r
prob <- chat@net[["prob", exact = TRUE]]
pval <- chat@net[["pval", exact = TRUE]]
stopifnot(!is.null(prob), !is.null(pval))
sum(prob > 0)
sum(prob > 0 & pval < 0.05)
```

Exact extraction avoids R's partial `$prob` match to `$prob.cell`.
`sum(NULL < 0.05)` is zero but means an absent stage, not valid nonsignificance.
Use `benchmarks/export_spatialcellchat_diagnostic.R` to collect the actual
input/result objects, parameters and function origins when another session
cannot be reproduced. A barcode-only file cannot identify preprocessing,
annotation or downstream filtering differences.

## Acceptance and status

The paired gate is active Jaccard=1, max absolute probability difference<=1e-15,
exact p-value fraction=1, and zero significance disagreements at p<0.05.
Successful execution and numerical-fidelity acceptance are separate statuses.
Changing official percentage filtering to the ESS rule is a causal diagnostic,
not a valid pass against the original formula.

Historical results keep their original version and parameter scope. A source
freeze, completed local checks, an unresolved collaborator case and cloud CI
not yet run must be reported separately. See `RELEASE_STATUS.md` for this build.

## Reproduce the small comparison

The fast check needs only SpatialESS and the bundled official-anchored fixture:

```sh
Rscript benchmarks/verify_lr_interface_mini.R .
```

For a fresh full official run, install the pinned reference into a separate R
library. Its dependencies must already be installed. From the repository root:

```sh
git clone https://github.com/jinworks/SpatialCellChat.git /tmp/SpatialCellChat-v3-reference
git -C /tmp/SpatialCellChat-v3-reference checkout be88f300464cf970b36a6165ea7d2e41a47a7511
git -C /tmp/SpatialCellChat-v3-reference apply "$PWD/validation/compatibility/official_dims_only.patch"
mkdir -p /tmp/spatialcellchat-v3-library
R CMD INSTALL -l /tmp/spatialcellchat-v3-library /tmp/SpatialCellChat-v3-reference
R_LIBS=/tmp/spatialcellchat-v3-library V3_WORKERS=4 Rscript benchmarks/verify_official_v3_mini.R . /tmp/spatialess-v3-result
```

Keep SpatialESS installed in a library on R's search path. Do not reuse a
nonempty reference checkout or output directory from another test. The live
check performs cell scoring, group averaging and 100 permutations on all
1076 shared LR under default 0.1/5 filtering. It writes inputs, environment,
records and a strict summary. This is slower than the frozen-reference check.
